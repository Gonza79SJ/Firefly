# 🌌 Firefly Fansite

¡Bienvenido a bordo de la *Serenity*! Este proyecto es un fansite web dedicado a la icónica serie de ciencia ficción **Firefly**, desarrollado como proyecto práctico interactivo.

---

## 🎓 Contexto Académico

* **Institución:** Escuela Da Vinci  
* **Carrera:** Analista de Sistemas  
* **Materia:** Programación Web  
* **Periodo:** 1er Cuatrimestre  

---

## 🚀 Características Principales

* **Página Principal (Index):** Banner principal hero con estética espacial, últimas noticias de la comunidad y frases célebres de la serie.
* **Guía de Episodios:** Listado completo de capítulos con sinopsis e información clave.
* **Sección de Reparto:** Fichas informativas sobre Malcolm Reynolds, Kaylee, Wash y el resto de los personajes.
* **Página de Error 404 Personalizada:** Pantalla temática ambientada en el universo de la serie (*Borde Exterior / Reavers*) para rutas no encontradas.
* **Diseño Responsive:** Layout adaptado para una navegación fluida en dispositivos desktop y móviles.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica de las páginas.
* **CSS3:** Estilos personalizados, Flexbox y CSS Grid.
* **Git & GitHub:** Control de versiones y alojamiento del repositorio.

---

## 📂 Estructura del Proyecto

* **index.html** - Página principal
* **404.html** - Página de error temática
* **/pages/episodios.html** - Guía de episodios
* **/pages/reparto.html** - Ficha de personajes
* **/pages/contacto.html** - Datos de Contacto
* **/pages/sobre.html** - Sobre este proyecto
* **css/global.css** - Hojas de estilo del proyecto
* **/img/** - Imágenes y recursos gráficos
* **/favicon/** - Iconografía
* **README.md** - Documentación del proyecto

---

## ⚡ Instalación y Uso Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/Gonza79SJ/Firefly.git
   ```

2. **Navegar al directorio:**
   ```bash
   cd Firefly
   ```

3. **Abrir en el navegador:**
   Abre el archivo `index.html` directamente en tu navegador web o ejecútalo mediante una extensión como *Live Server* en Visual Studio Code.
