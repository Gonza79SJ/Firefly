Acerca de este proyecto

El Proyecto Fansite

Este sitio web fue desarrollado como un espacio de culto dedicado a la serie Firefly (2002). El objetivo principal es ofrecer un repositorio centralizado, limpio y accesible con información técnica sobre la producción, la tripulación de la nave Serenity y su guía cronológica de episodios.

Sobre el Desarrollador

¡Hola! Soy estudiante de la carrera de Analista de Sistemas. Este sitio web forma parte de una entrega práctica para la materia de Programación Web.

Además del desarrollo de software, me apasionan las tecnologías emergentes, la automatización, los flujos de trabajo inteligentes y el diseño orientado a la impresión y modelado 3D. Para el armado de este sitio web, se aplicaron estándares modernos de maquetación pura utilizando HTML5 semántico, garantizando una base sólida y estructurada lista para la futura implementación de hojas de estilo CSS.
